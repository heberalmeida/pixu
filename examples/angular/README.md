# Pixu Angular Example

Complete working example of Pixu Angular component.

## Installation

1. Install dependencies:

```bash
npm install
```

2. Make sure Pixu is built:

```bash
cd ../..
npm run build
```

## Running

Start the development server:

```bash
npm start
```

The application will open at `http://localhost:4200`

## Build

Build for production:

```bash
npm run build
```

## Requirements

- Node.js 18+
- npm or yarn
- Angular CLI 17+
