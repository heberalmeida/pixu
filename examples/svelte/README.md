# Pixu Svelte Example

Complete working example of Pixu Svelte component.

## Installation

1. Install dependencies:

```bash
npm install
```

2. Make sure Pixu is built:

```bash
cd ../..
npm run build
```

## Running

Start the development server:

```bash
npm run dev
```

The application will open at `http://localhost:3002`

## Build

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## Requirements

- Node.js 18+
- npm or yarn
- Modern browser (Chrome, Firefox, Safari, Edge)
