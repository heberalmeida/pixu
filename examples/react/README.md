# Pixu React Example

Complete working example of Pixu React component with multiple compression scenarios.

## Installation

1. Install dependencies:

```bash
npm install
```

2. Make sure Pixu is built:

```bash
cd ../..
npm run build
```

## Running

Start the development server:

```bash
npm run dev
```

The application will open at `http://localhost:3001`

## Build

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## Features Demonstrated

1. Basic Compression
2. Advanced Options
3. Compression Presets

## Requirements

- Node.js 18+
- npm or yarn
- Modern browser (Chrome, Firefox, Safari, Edge)
